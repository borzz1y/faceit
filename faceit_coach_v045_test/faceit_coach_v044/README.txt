FACEIT Coach 0.4.5 - training scenarios test build

Open index.html in a desktop browser. Training scenarios now provide structured steps, local-map console commands, server-IP connect commands, and copy-command support. Favorites and profile data are stored in the current browser's localStorage.

Important limitations: this is still a front-end prototype. FACEIT search, login, match history and stats are demo-only and not connected to the real FACEIT API. The page cannot start CS2, manage bots, or run commands in the game automatically; copy the displayed command into the CS2 developer console. Server connection requires a real server address and valid access.
